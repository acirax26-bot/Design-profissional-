## Código de linha em blocos de código 

O comando `git commit -m "Mensagem de comentário"` registra as alterações com uma mensagem.

O comando `git push` envia os arquivos para a nuvem.

``` 

git status 
git add .
git commit -m "Mensagem de comentário"
git push
```
